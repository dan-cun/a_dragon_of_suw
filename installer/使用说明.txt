西大日常 1.0.0-beta · 查寝与乐跑整合版

安装后从桌面或开始菜单打开“西大日常”。升级原打卡助手会保留查寝设置、历史、计划、会话和自启动；业务忙碌时等待结束后再升级。
查寝：沿用今日任务、坐标、时间安排、暂停/请假、热力和记录。会话失效时可点“重新登录”。首次勾选“记住登录”并成功登录后，账号密码和学校 Cookie 会用 Windows 加密保存，失效后尝试恢复；学校要求验证码时仍需本人填写，不保证永久登录。偏好设置可忘记登录信息，退出账号会同时删除。请假日期仍需自行登记，未接入学校请假单同步。
校园服务：侧栏查看课表、成绩与考试。先登录本人账号，再连接教务；助手会通过已登录的学校门户查询教务入口并继续正常 SSO。会话失效时复用同账号保存密码与内置 OCR 自动认证一次；识别失败或学校拒绝会明确提示。未保存密码时在官方窗口完成登录，再回应用重新检测。学号一致后选择学期查询。 页面加载完成及每次数据查询前随机等待 1–3 秒，再继续下一步。仅在本机读取，保留现有代理，不修改教务数据；结果显示读取时间，断开或退出后清除本次结果。
乐跑：合并项目从 1.0.0-beta 开始独立版本编号，保留旧安装标识和用户数据以支持覆盖升级。首次使用按页面四步操作：添加成员 → 准备电脑 → 采集会话 → 验证与结果。只展开当前一步，已完成步骤可回看，数据维护与日志按需展开，按钮旁说明缺少的条件。添加并选择本人或已获同意的成员，先做环境检查。会话使用后清除不代表提交失败；最近提交摘要重启后保留，上次结果不是实时查询，先核对已有记录。首次采集需点击“安装证书”，将本应用代理证书安装到当前 Windows 用户根证书库。安装后按指纹复核受信任状态，查询失败会明确报告，不当成未安装。
默认保留现有网络配置；采集和完整执行需明确允许本次临时切换系统代理，授权不保存。不会修改 Clash 等软件的节点、规则、订阅或自启动。“开始采集登录会话”不提交；“验证当前会话 · 不提交”仅启动本机 API 代理、读取平台数据，不改系统代理、不上传或提交；完整执行入口单独折叠并注明会提交。“采集并执行乐跑”沿用上游执行与复核。在采集时通过电脑微信打开“数体智慧体育”。
采集身份必须与所选成员一致，身份冲突明确停止，不自动切换其他成员。结果按成员和操作编号归属，主动取消与超时分别显示；执行阶段中断仍需到平台核对是否受理，勿盲目重复。采集通过 Windows 默认连接接口设置并复核代理，不只修改普通注册表字段；恢复时保留原代理、绕过和自动配置设置。微信若在采集前已打开，需从微信菜单正常退出再重开，并进入数体智慧体育的校园乐跑页，不必开始运动。采集临时使用系统代理，结束后恢复；默认不退出微信，不清理微信登录态。“停止并恢复代理”需等待当前请求结束，完成前不能退出或升级。
两个模块互斥执行，乐跑期间查寝调度等待；乐跑不会随查寝定时自动运行。查寝按账号、日期、任务独立防重；未确认结果累计最多自动回查 3 次，重启不会重置，也不会再次提交。
关闭窗口后托盘继续运行；验证码、认证失效、结果待确认等状态会提醒。双击托盘返回，右键或偏好设置可退出。系统通知/勿扰设置可能阻止弹出，可在偏好设置测试提醒。电脑须开机、联网且会话有效。
本机数据：%APPDATA%\swu-daka-desktop；乐跑在 lepao 子目录，配置、会话和执行记录使用 Windows 当前用户加密。会话本地最多保留 24 小时，并非平台有效期保证；采集材料在启动、结束和退出时清理。可清除所选会话、清理采集材料，删除成员会清理其凭据和可归属记录；共享采集材料也被清理，其他成员加密会话保留。代理未恢复时拒绝清理。证书单独保留，勿转发数据目录。卸载保留数据及用户主动安装的证书。
