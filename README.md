## 安装与查寝

运行“西大日常-1.0.0-alpha-基础版-安装程序.exe”，然后从桌面或开始菜单打开“西大日常”。支持 Windows 10/11 x64，需要系统 Edge；包内包含 Python 乐跑引擎与代理，无需另装 Python 或 Bun。分发时请发送完整安装程序。

安装使用原查寝版的安装标识和目录 %LOCALAPPDATA%\Programs\SWU-Daka，升级先请求旧后台正常退出。业务忙碌时拒绝退出和升级。原 %APPDATA%\swu-daka-desktop 中的查寝设置、DPAPI 会话、随机计划与历史保留，旧当天标记保守迁移为任务记录，自启动仍指向固定目录。

查寝沿用 2.4.2 的同步、坐标、手动执行、固定或随机时间、暂停/请假日期、热力与日志；只有回查确认学校已签到时显示成功。学校请假单自动同步仍未接入。

## 独立任务记录、结果回查与后台提醒

提交前按账号、任务日期和任务 ID 保存防重记录。某项任务已发起提交、结果未知或已确认时，不会再次提交这项任务；其他独立任务分别判断。旧版当天标记在第一次成功同步时迁移：当时已发布的任务均先保护，已签到项记为确认，未确认项只回查；不会根据旧标记猜测允许重发。

提交后立即查询学校结果；未确认则后台最多累计 3 次自动核对，包括首次回查。后续逻辑回查间隔为 15 秒、45 秒，重启保留次数和状态；底层只读接口仍有最多 3 次暂时性故障重试。达到上限后显示需人工核对。回查仅调用 select，不调用 save；手动同步仍可更新已确认结果。历史记录在取得学校确认后更新为成功。

自动调度不再因一个任务已完成而阻止其他任务；已知任务已处理时每 5 分钟检查新安排，空列表每 60 秒检查。随机时间段只决定计划开始时间：同步到学校任务后，自动检查持续到该任务窗口结束，不会因为设置里的结束时间提前停止；当天尚未同步过的重启会先补一次状态发现。存在多个同时开放的新任务时仍要求打开界面选择，不随意选择。暂停/请假日不执行自动签到调度；已经提交过的任务仍可进行有限只读回查。关闭随机时间段后不补交。

后台常驻 Windows 托盘，双击或点击通知打开界面，右键可退出；忙碌时明确拒绝退出。需要验证码、认证失效、调度异常、结果未确认或定时任务完成时提醒，同一事件去重；启动时不重放旧日志。偏好设置可测试后台提醒。提醒由 Windows NotifyIcon 接受，最终是否弹出由系统通知与勿扰设置控制，不以接收回执冒充本人已看到。

数据格式升级为 schemaVersion 5，保留原 session/settings/history 和旧日期字段供迁移，不再用单个日期字段决定所有任务是否允许提交。

## 记住登录与认证恢复

登录时可勾选“记住登录，认证失效后尝试自动恢复”。只在身份核验成功后，将账号密码及学校 Cookie 一起用 Windows DPAPI 加密保存到 login-memory.json，不保存明文，不把已保存密码返回给页面。下次需要验证码时，界面可选“使用已保存的密码”，并自动识别填入验证码；取消或失败不覆盖旧记录。

应用接口认证失效后，若已保存登录信息，每个后台进程最多发起一次自动恢复尝试，优先把已保存的学校 Cookie 恢复到新的隔离认证窗口，通过正常 SSO 换取新应用令牌。若学校要求验证码，登录窗口会用随包 ddddocr 自动识别并填入，识别有误时可修改后登录；不重复猜测密码。完整同步成功后恢复尝试预算。当日计划、请假和提交标记均保留，不重发已经开始的提交。暂停/请假日不会因为后台调度额外发起认证请求。

偏好设置中的“自动登录（打卡）”是显式开关，默认开启，只有保存过登录信息后可用。开启时，认证失效会自动使用保存的密码，并在验证码自动识别成功后直接提交；识别失败或关闭开关时停在登录窗口等待人工处理，不会自动重试密码。定时打卡遇到认证失效时，自动登录成功后会继续执行当天尚未完成的定时签到；每个后台进程只自动尝试一次登录。

此功能不等于永久登录：是否接受 SSO、是否要求验证码由学校决定。首次使用需在本版登录窗口勾选并成功登录一次；旧版未保存密码，无法凭旧令牌还原密码。偏好设置“忘记登录信息”删除保存的账号密码和学校 Cookie，保留当前应用令牌；“退出账号”同时删除记住信息并关闭定时。

DPAPI、页面与取消/删除行为已通过本机验证；2026-10-16 已用授权账号完成真实登录、一次查寝签到及独立确认，并验证保存的有效学校 Cookie 可不填写密码或验证码直接完成 SSO 换应用令牌。此结果不代表学校令全部 Cookie 失效后仍能免验证码，也不保证永久可用。

## 乐跑

首次进入按页面四步操作：添加并选择成员 → 检查本机环境与首次证书准备 → 配合电脑微信采集会话 → 验证并核对结果。仅展开当前一步，各步骤可点击回看；数据维护和日志默认折叠。采集和验证按钮旁直接说明缺少的条件。状态读取失败后明确停止更新并保留上次状态，仍可手动重新读取或请求停止；恢复读取前禁用新操作。删除成员及本地记录前显示所选成员和影响范围，可取消。页面说明学校编号与学号、电脑微信与手机微信的区别。证书用途、采集超时和停止后的处理均可展开查看。

“采集完成”“只读验证完成”“平台复核通过”和“待复核”分别解释，不把采集或干跑成功当作已产生运动记录。完整执行入口单独折叠，明确会重新采集并向平台提交；成员删除、会话清除等维护操作放在数据区域。引导来自当前成员和真实检查结果，浏览或跳转步骤不会自动安装证书或提交。

采集凭据在写入前核对目标成员和身份字段；未知、歧义或冲突身份均拒绝，不回退到默认成员。复核查询也使用本次目标成员。操作结果携带操作编号、成员、开始/结束时间、阶段、取消请求与代理恢复状态，切换成员不将其他成员结果当作当前结果。停止与超时分别显示；进入执行后中断时仍要求核对平台记录，不声称未提交。最近操作上下文仅保留在当前引擎进程中；所选成员的最近提交摘要从加密本地记录读取，重启后仍显示提交时间、距离、用时和上次平台状态，不伪装成实时查询。今日已有提交时引导核对已有结果，会话“已使用”不代表提交失败。

乐跑使用独立成员和会话，不复用校园登录令牌：

1. 添加并选择本人或已经明确同意的成员，核对姓名、学号和学校编号。837 沿用上游默认学校编号，须以实际账号为准。
2. “环境检查”读取本机代理、微信、证书与声明状态，不采集、不改变系统代理、不提交记录。
3. 首次采集前点击“安装证书”，将本应用独立代理证书安装到当前 Windows 用户的受信任根证书库，不安装到本机全局库。
4. 明确允许本次临时切换系统代理后，点击“开始采集登录会话”，等页面显示“等待电脑微信登录”后，再在电脑微信打开“数体智慧体育”。“采集并执行乐跑”沿用上游完整执行与复核流程。
5. “验证当前会话 · 不提交”只启动本机 API 代理并读取平台配置、额度和生成本地材料，不改系统代理，不上传或提交运动记录；“停止并恢复代理”等待当前请求退出并恢复代理后结束。

证书状态通过 Windows Crypt32 只读查询根证书库，不依赖 PowerShell 的 Cert: 驱动；安装命令结束后必须按当前证书指纹复核，未确认受信任不显示安装成功。手动环境检查会刷新证书缓存，查询错误明确报告，不当成未信任。

采集使用 WinINet 默认连接接口设置当前用户代理，并同时复核普通字段与默认连接配置；恢复时保留原代理、绕过规则、自动配置地址及连接标志。Windows 查询或刷新失败明确报错。采集前已经打开的电脑微信可能保留旧代理，需从微信菜单正常退出再重开，再进入“数体智慧体育 → 校园乐跑”；无需点击开始乐跑。

采集会临时修改当前用户系统代理。只停止本应用持有的代理进程，并等待确认退出后释放引用，监听限定本机；端口占用明确失败，不结束其他代理。停止进程和恢复网络分别尝试，失败明确上报；仍存活的本应用监听或未恢复备份都会阻止新操作，恢复后重新核对普通字段和原生连接配置。默认不退出微信、不清理微信登录态。若其他程序在运行中修改代理，本版报告恢复冲突并保留备份，不覆盖他人的新设置。

查寝和乐跑动作互斥；乐跑期间查寝调度等待，结束后继续检查原计划，不重新抽取时间。乐跑未新增无人值守定时，不会随查寝定时自动执行。结果沿用上游的成功、待复核、无效、缺少会话等状态；未终判不显示成功。2026-10-17 已完成一条真实乐跑提交和平台有效性回查；该次结果不保证后续所有记录均获认可。

## 数据

乐跑数据在 %APPDATA%\swu-daka-desktop\lepao，首次为空成员表。config.json、凭证.json 和 state.json 使用 Windows CurrentUser DPAPI 加密，旧明文 JSON 原子迁移且不另存明文备份。无法解密或格式错误会明确失败。界面不返回令牌或令牌前缀，脱敏日志仅在当前后台内存中保留，最多 300 条。

本地会话保留上限为 24 小时，已使用、过期或时间无效的凭据被清除；此上限不是平台有效期保证，平台可更早失效。清除所选会话保留成员资料；删除成员同时移除其凭据及可归属的本地执行记录。重新采集后使用新会话。

默认不调整现有系统代理。采集和完整执行前必须勾选“允许本次采集临时切换 Windows 系统代理”，授权不保存，每次操作单独选择；界面、HTTP 接口和引擎均校验授权。不提交验证仅启动本机 API 代理，不改变系统代理，不修改 Clash 等代理软件的配置。采集期间若检测到代理被其他程序更改，会停止并报告，不自动抢写；先恢复再排查。

正常采集不保存原始流文件或明文请求日志。启动、操作完成和正常退出时清理 flows、logs、共享采集凭据与最近干跑材料；界面可手动清理。原始材料为共享文件，清除会话或删除成员也会清理这些共享材料，其他成员的加密会话保留。代理未恢复时拒绝清理并明确提示；不跟随符号链接或目录联接删除，不删除无关文件。旧版位于用户数据根目录的 mitm_流量.log 也纳入固定范围清理。

独立证书及私钥保存在 certificates 子目录，沿用代理需要的文件形式，不替换原有 ~/.mitmproxy 证书，不随会话清理删除。

卸载保留用户数据及用户主动安装的证书。移除证书时，在当前用户证书管理器核对本应用 certificates 公钥指纹后删除相符项，勿删除其他代理证书。

## 开发

desktop/ 为 Bun + React 界面和服务；engine/bridge.py 为 JSON-lines 适配器；vendor/lepao3/ 保留原声明的上游实现。引擎首次进入乐跑页才启动。Node 和 Python 依赖分别由 bun.lock、requirements.lock 锁定，项目环境在 D:\Code\swu-campus-assistant。

```powershell
uv pip sync requirements.lock --python D:/Code/swu-campus-assistant/python/Scripts/python.exe
bun install --frozen-lockfile
$env:SWU_PYTHON = 'D:/Code/swu-campus-assistant/python/Scripts/python.exe'
$env:SWU_ENGINE_DIST = 'D:/Code/swu-campus-assistant/engine-dist-1.0.0-beta/lepao-engine'
$env:SWU_ENGINE_BUILD = 'D:/Code/swu-campus-assistant/engine-build-1.0.0-beta'
$env:SWU_BUILD_OUTPUT = 'D:/Coding/swu-campus-assistant/1.0.0-beta'
$env:SWU_TEST_EXE = "$env:SWU_BUILD_OUTPUT/打卡助手.exe"
# Set SWU_INNO_COMPILER to the verified local ISCC.exe path.
bun run build:engine
bun run typecheck
$env:SWU_LEPAO_ENGINE = "$env:SWU_ENGINE_DIST/lepao-engine.exe"
bun run test
& $env:SWU_PYTHON tests/privacy-smoke.py
& $env:SWU_PYTHON tests/proxy-smoke.py
& $env:SWU_PYTHON tests/lepao-flow-smoke.py
bun run build
bun run test:desktop
bun run build:installer
```

主程序构建要求完整引擎，收集 npm/Python 许可证，生成程序与引擎全部文件的 SHA-256 清单，安装包编译前复核。SWU_USER_DATA_DIR 隔离测试数据；SWU_LEPAO_ENGINE 可覆盖开发用引擎路径。默认测试不提交学校签到/乐跑，不安装证书或修改系统代理。旧可选真实失效会话测试仅在显式提供 SWU_TEST_SESSION_SOURCE 时运行。

上游声明检查：用项目 Python 执行 vendor/lepao3/tools/apply_headers.py --check。许可证使用上游原 Git blob 字节，避免 CRLF 转换误报。乐跑轨迹与提交算法沿用上游，本版不保证平台认可结果。H5 登录、CLI 批处理与 Tk 界面没有作为独立入口开放，界面接入的是成员、环境、会话采集、干跑和完整执行。
