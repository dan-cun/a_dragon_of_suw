# 用 WorkBuddy 协助操作西大日常

这是一条**外部软件协作路径**，不是西大日常的模型协议，不要求把 WorkBuddy 填进 API 地址，也不是已经接通的远程控制功能。本教程适用于本人电脑、本人明确授权的排查和软件使用协助。

## 1. 确认产品并安装

这里指腾讯的 **WorkBuddy**，不是 CodeBuddy IDE、浏览器扩展或同名第三方软件。使用官方产品入口下载，不从搜索广告或不明网盘安装。[WorkBuddy 官网](https://www.workbuddy.cn/ "腾讯 WorkBuddy 官方产品与下载入口")

根据官方 Windows 安装说明：

1. 官网点击「立即下载」，选择 Windows；要求 Windows 10 及以上、Windows x64，ARM64 支持以当前版本说明为准。
2. 下载后运行安装程序，阅读协议，核对安装位置与快捷方式后安装。
3. 启动并点击登录，由本人在官网完成登录，再返回客户端。具体登录方式与界面以当前版本为准，不把登录二维码或验证码交给助手。
4. 后续更新可从左下角头像的「检查更新」进入。

以上步骤来自官方，不固定某个安装包版本或猜测二进制直链。[WorkBuddy Windows 安装指南](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Installation-Win-Guide "WorkBuddy 官方说明 Windows 系统要求、安装、登录和更新步骤")

## 2. 先确认它究竟能控制什么

WorkBuddy 的官方 Agent Browser 教程确实说明了网页打开、滚动、点击、展开、截图和读取等**浏览器级操作**，安装名为 `agent-browser`，列于 SkillHub。[WorkBuddy Agent Browser](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/WorkBuddy-Zero-Cost-Skill-Top-10/Agent-Browser "WorkBuddy 官方说明 Agent Browser 用于网页交互与截图")

**这不能证明它能控制西大日常的 Windows 原生窗口。** 本教程核实的官方资料没有给出针对西大日常的桌面控制接口、插件、服务地址或连接方法，因此：

- 不宣称 WorkBuddy 已与本应用集成，不提供虚构的 API、MCP、调试端口或远控地址。
- 不把本应用受保护的本机网页端口、launch key、浏览器会话或用户数据目录交给外部助手。
- 不要求关闭本应用鉴权、开启远程调试、修改系统代理或暴露端口来“打通”。
- 本人所装版本若有额外软件控制工具，也必须先查该工具的官方文档与权限范围。本教程不代替其安装和授权说明，不能保证菜单或能力存在。
- 无法明确确认桌面控件识别能力时，使用下一节的**人机协作操作流程**。不是自动远控成功，也不靠坐标盲点弥补缺失能力。

可先给 WorkBuddy 这段任务，要求只报告能力、不要操作：

```text
我想让你协助使用西大日常 SWU。当前先做 diagnose，不执行任何操作。
请先报告你在这个会话中实际可用的工具与权限：
1. 能否读取我主动提供的脱敏文字或截图？
2. 是否有官方支持的 Windows 原生窗口识别与操作工具？如果有，给出准确工具名、官方说明和权限边界；没有就明确说没有。
3. 请区分浏览器网页操作与 Windows 桌面软件操作，不要用 Agent Browser 的能力推断桌面可控。
不要连接本机私有端口，不要读取文件、账号、密钥、Cookie 或学校会话。
在我明确授权某个具体动作前，不点击、不输入、不安装、不执行命令。
```

助手的自述不等于已经通过验证，必须与实际工具和官方资料核对。不能核实就停止自动控制。

## 3. 人人可用的协作操作流程

不依赖远控接口即可协助排错：

1. **本人启动软件**：正常打开西大日常，不把正式账号或配置文件发给 WorkBuddy。
2. **本人整理现象**：进入「Pi 助手」→「Pi 辅助与使用教程」，选择网课、练习或安装/模型配置场景，填写复现步骤、预期、实际结果。不要复制整份日志或请求头。
3. **本人脱敏并预览**：去除学号、姓名、账号、Key、Cookie、课程隐私与签名 URL。诊断区不会自动脱敏。查看生成的只读提示词后，勾选检查确认，再点击复制。
4. **本人主动交给助手**：在 WorkBuddy 中创建普通任务，粘贴提示词，要求先诊断、分辨事实与推测。若需要截图，由本人裁剪和遮挡敏感信息后提供；不要允许它遍历本机截图或账号目录。
5. **按步骤操作**：让助手每次仅给一个具体的人工操作步骤，本人在西大日常中操作后反馈脱敏结果。登录、验证码和 Key 一律由本人填写。
6. **对照真实结果验收**：配置保存只算配置保存，模型请求须看实际响应，浏览器启动不算平台登录或课程完成。无法验证就标记“未验证”。
7. **结束协作**：清空诊断输入，按需清理系统剪贴板和 WorkBuddy 会话。清空本页不会撤回外部聊天、截图、剪贴板历史或云端记录；如误发 Key，应在对应官方平台撤销并重建，不能仅删除消息。

### 示例：网课页空白 / 控件异常

- 只提供应用版本、自己打开的页面、错误码和脱敏现象；不提供课程登录资料。
- 先要求区分网络、页面加载、浏览器状态、脚本依赖与应用未实现的能力。
- 不自动重启全部浏览器、不安装未知脚本、不绕过平台限制、不自动观看课程或提交完成记录。

### 示例：练习结果异常

- 仅排查显示/保存状态，或讲解本人有权使用的练习知识点。
- 平台是否收到答案以本人在官方页面核实为准；超时不代表未提交，不能盲目重发。
- 不代考、不自动刷题提交、不绕过反作弊或验证码。

## 4. 如果已另行核实某个软件控制工具

仅在真实工具存在、官方支持且本人理解权限后考虑 `execute`。这是权限核对模板，不是西大日常提供的新功能，也不替任何工具作能力承诺：

```text
任务模式：execute，只有以下一次具体动作获授权。
目标：我已打开的西大日常窗口，只进入 Pi 助手页面并展开使用教程。
禁止：读取账号或文件、查看或输入密钥、调用模型 API、保存/删除配置、修改代理、安装证书、登录学校、控制其他软件、提交课程/答案/签到/运动记录。
先报告将使用的实际工具与稳定控件标识，等我确认后才操作。
找不到稳定 ID、test ID 或辅助功能标识时立即停止，不按可见文字猜位置，不使用坐标盲点或回退点击。
完成后报告实际观测结果；操作失败明确说明，不把计划写成已执行。
```

本应用教程组件的稳定测试标识包括 `pi-assistance`、`pi-guide-deepseek-toggle`、`pi-guide-workbuddy-toggle`、`pi-guide-assistance-toggle`、`pi-diagnosis-scenario`、`pi-diagnosis-steps`、`pi-diagnosis-preview` 等。**有这些标识不意味着 WorkBuddy 能访问本应用的 DOM 或控件**；不要为了使用标识而绕过本机页面保护。

不授予无限制“帮我搞定”的权限。`diagnose` 与 `execute` 必须分开，点击发送给模型也属于明确的网络与可能付费操作。

## 5. 限制与其他入口

- WorkBuddy 的账户、模型、计费和记录属于该外部产品；不等于西大日常的 DeepSeek API 配置，也不由本应用的 DPAPI 保护。
- 目前没有针对本应用的已验证 WorkBuddy 原生桌面远控链路；本教程提供的是可靠的安装入口、权限核对和人工协作步骤。
- 不需要 WorkBuddy 也能使用本应用模型配置或复制诊断提示词。使用哪一家助手由本人选择，不自动读取其他软件的凭据。
